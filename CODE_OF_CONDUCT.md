# Code of Conduct

Be respectful and constructive. Harassment, personal attacks, or discriminatory
language are not welcome in issues, pull requests, or discussions.

Report unacceptable behavior privately through the repository's **Security** tab
(*Report a vulnerability*) or the contact on my GitHub profile. Maintainers may
remove comments, commits, or contributions that violate this standard.

This is a condensed code of conduct adapted from the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
