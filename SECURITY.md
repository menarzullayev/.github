# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's **[Private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)**
(the **Security** tab → *Report a vulnerability*) on the affected repository.

Include: affected repo and version/commit, impact, and steps to reproduce.
I aim to acknowledge within a few days.

## Supported versions

Unless a repository states otherwise, only the latest default-branch state is
supported.

## Secrets

These repositories never contain credentials. Tokens, session strings, and API
keys live outside version control. If you believe a secret was committed, report
it privately as above so it can be rotated.
