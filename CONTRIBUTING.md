# Contributing

Thanks for your interest. These are my personal / product repositories; most are
solo-maintained, so please open an issue to discuss before large changes.

## Workflow

1. Branch off the default branch (`feat/...`, `fix/...`).
2. Keep commits focused and use **[Conventional Commits](https://www.conventionalcommits.org/)**:
   `type(scope): subject` — `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `ci`, `build`, `perf`.
3. Run the repo's checks locally (lint, types, tests) before pushing.
4. Open a PR; fill in the template. CI must be green before merge.

## Code style

- Code comments and docstrings in **English**.
- No generated/AI attribution trailers in commits or PRs.
- Don't commit secrets, local config, or unrelated files. Review your diff first.
